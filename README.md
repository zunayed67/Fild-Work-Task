# 🌐 Personal Portfolio — Zunayed Hossain

A modern, responsive, and premium-looking personal portfolio website built to showcase my profile, technical skills, educational background, and contact information.

Designed with a clean dark theme, elegant typography, gradient effects, and smooth animations to create a professional digital presence.

## ✨ Features

- **Modern UI/UX:** Premium dark-themed interface with gradient accents and glassmorphism effects.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Hero Section:** Personal introduction with an animated typing effect.
- **About Me:** Overview of my background, interests, and career goals.
- **Skills Showcase:** Highlights my technical skills and development technologies.
- **Education:** Structured academic background and achievements.
- **Social Integration:** Direct links to GitHub, LinkedIn, Facebook, and Email.
- **Contact Form:** Integrated with FormSubmit for email-based message delivery.
- **Interactive Navigation:** Mobile menu and active section highlighting.
- **Scroll Animations:** Smooth reveal effects and interactive UI elements.
- **Back to Top:** Convenient navigation for a better user experience.

## 🛠️ Technologies Used

| Technology   | Purpose                          |
| ------------ | -------------------------------- |
| HTML5        | Website Structure                |
| CSS3         | Styling, Layout & Animations     |
| JavaScript   | Interactivity & DOM Manipulation |
| Font Awesome | Icons                            |
| Google Fonts | Typography                       |
| FormSubmit   | Contact Form Email Delivery      |
